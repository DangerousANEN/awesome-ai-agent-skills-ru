## 🛠 Категории Навыков

### 1. 🎬 Моушн-дизайн и Видеопроизводство
- [`motion-studio-pro`](#): Автоматическая генерация 9:16 Shorts/Reels на Remotion, GSAP и Qwen3-TTS/CosyVoice 3.
- [`video-render-engine`](#): 60 FPS рендеринг WebGL/Canvas с караоке-субтитрами.

### 2. 🧠 Сжатие контекста и память
- [`context-compressor`](#): Сокращение 60–90% избыточных токенов в JSON и кодовой базе.
- [`llm-wiki-memory`](#): Двухуровневая память для агентов с сохранением связей между сессиями.

### 3. 🔍 Поиск и Аналитика
